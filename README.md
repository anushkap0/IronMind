# 🏋️ IronMind – AI Fitness Coach

IronMind is a full-stack AI-powered fitness platform that helps users track their health, generate personalized workout and diet plans, analyze exercise form, and interact with an intelligent AI fitness coach.

The application combines modern web technologies, AI/ML, computer vision, real-time communication, and secure authentication into a single fitness ecosystem.

---

## 🚀 Features

- 🔐 JWT Authentication & Google Sign-In
- 📊 BMI Calculator with History & Progress Charts
- 🤖 AI Fitness Coach with RAG Chatbot
- 🥗 Personalized Diet & Workout Plan Generator
- ⏱️ HIIT, Tabata & Custom Workout Timers
- 📹 AI Exercise Form Checker using MediaPipe Pose
- 🔢 Real-Time Exercise Rep Counting
- 📐 Joint Angle & Form Analysis
- 🔔 Real-Time Notifications using Socket.IO
- 🏆 Daily Streaks & Achievement Badges
- 📧 Daily Email Workout Reminders
- 🌙 Dark/Light Theme
- 🎨 Animated UI with Framer Motion
- 🛡️ Rate Limiting & Secure Authentication
- 🧪 Backend Unit Testing with Pytest
- 🐳 Docker & Docker Compose Support
